Visual Identity

A coastal-inspired visual system for a portfolio about 3D modeling, animation, and interactive environments. Soft colour and editorial type express imagination; precise monospaced details reflect the technical side of making digital worlds.

Creative Direction

Soft · Elegant · Imaginative · Technical

Use quiet surfaces and restrained decoration so the actual project work remains the focus.

Portfolio ethos

Worlds in the Making

Creating digital worlds through modeling, movement, atmosphere, and interaction.

Colour Palette

Six reusable colour tokens, including a deeper text colour for legibility.

Lavender Mist #E6E3F4 · Soft background

Coastal Lilac #C9C3E8 · Accent and surfaces

Ocean Foam #F8F6F0 · Primary canvas

Driftwood #DCD7E4 · Borders and muted panels

Sunlit Sand #F7E8C7 · Warm accents

Deep Iris #4B486D · Text and contrast

Gradients

Gradients use only colours from the palette. Keep most content surfaces neutral to avoid visual clutter.

Misty Dream Background sections

Lilac Haze Featured panels

background: var(--haze);

Sunset Glow Warm accents

background: var(--sunset);

Sample code

Text & Links

Shared Text Link (Navbar, Sidebar, Body & Footer)

Media & Accessibility

Media Conventions

  • Use original project screenshots with meaningful alt text.
  • Use figure and figcaption for process evidence.
  • Preserve image proportions; avoid stretched artwork.
  • Credit third-party assets and collaborators.

Accessibility

  • Maintain visible keyboard focus states.
  • Use semantic headings and landmarks.
  • Use Deep Iris on pale backgrounds for body text.
  • Respect reduced-motion preferences and responsive layouts.
